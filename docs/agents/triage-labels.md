# Triage Labels

技能使用五个标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| -------------------------- | ---------- | ---- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 issue |
| `needs-info` | `needs-info` | 等待报告人补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全明确，可供 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 / 决策 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如“应用 AFK-ready triage 标签”）时，使用本表中对应的标签字符串。

如果本仓库实际使用的标签名不同，编辑右列即可。
